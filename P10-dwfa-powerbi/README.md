# P10 — DWFA : priorisation de l'accès à l'eau potable
 
## Contexte
Drinking Water For All (DWFA), organisation fictive intervenant sur
l'accès à l'eau potable dans le monde.
 
## Problème métier
Identifier les pays où l'accès à l'eau potable est le plus difficile,
pour prioriser 3 axes d'intervention : création de service, modernisation
de service, conseil.
 
## Démarche
- Modélisation de données en étoile
- Résolution de plusieurs blocages réels rencontrés en construction :
  paramètres régionaux causant des erreurs de conversion décimale,
  doublons de la Chine faussant la population mondiale affichée de
  +1,5 milliard, synchronisation incorrecte de filtres entre pages
 
## Résultat
Dashboard Power BI multi-pages conforme à la grille d'évaluation :
3+ vues, représentations temporelles et géographiques, 4 filtres
(quantitatif/qualitatif/temporel/géographique), modèle en étoile,
accessibilité.
 
## Compétences démontrées
Modélisation de données, DAX, storytelling géographique, résolution de
bugs de données réels, accessibilité.
 
## Outils
Power BI
